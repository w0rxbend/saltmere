If you have ever wired up a CCS811 or an SGP30 and watched "CO2" spike when you opened a bottle of hand sanitizer, you already know the problem: those parts do not measure CO2. They measure total VOCs and print an **eCO2** number derived from a model that assumes human breath is the only thing polluting the air. The moment isopropyl alcohol, cooking fumes, or a fresh coat of paint enters the room, the estimate falls apart.

The Sensirion SCD41 measures the real thing. It is a **photoacoustic NDIR** sensor: an IR emitter pulses at CO2's absorption band, gas molecules in a tiny cavity absorb that energy and expand, and a MEMS microphone hears the resulting pressure pulse. More CO2 means a louder acoustic signal. Because it is tied to CO2's specific IR absorption, VOCs do not fool it. That is why it belongs in any air-quality monitor where you actually care about ventilation and occupancy, not just "something smells."

## The I2C interface

The SCD41 sits at **7-bit address 0x62** and speaks I2C up to **400 kHz**. Every command is a 16-bit code sent big-endian (MSB first). The three you need for a basic logger:

| Command | Code | Notes |
|---|---|---|
| `start_periodic_measurement` | `0x21B1` | Begins auto-sampling every 5 s |
| `get_data_ready_status` | `0xE4B8` | Returns a word; low 11 bits nonzero = ready |
| `read_measurement` | `0xEC05` | Returns 9 bytes: CO2, T, RH |
| `stop_periodic_measurement` | `0x3F86` | Needed before most config commands; ~500 ms |

Once you send `start_periodic_measurement`, the sensor produces a fresh sample **every 5 seconds**. Do not poll faster than that in periodic mode; you will just re-read the same value. Also note that configuration commands (altitude, ASC, etc.) are only accepted in **idle mode**, so you must stop periodic measurement first, configure, then start again.

## CRC-8 on every word

This is where naive drivers go wrong. `read_measurement` returns **three 16-bit words, each followed by its own CRC-8 byte** — nine bytes total, not six. The CRC is computed over the two data bytes with **polynomial 0x31 (x^8 + x^5 + x^4 + 1) and init 0xFF**. If you skip the checksum you will occasionally accept a garbled word as a real reading, which shows up as a random 40000 ppm spike in your graph.

The conversions, straight from the datasheet:

- **CO2 [ppm] = word0** (already in ppm, range 0–40000)
- **T [degC] = -45 + 175 * word1 / 65535**
- **RH [%] = 100 * word2 / 65535**

SCD41 accuracy for CO2 is ±(50 ppm + 2.5% of reading) from 400–1000 ppm, widening to ±(50 ppm + 3%) up to 2000 ppm.

## Minimal ESP32 sketch (raw I2C)

No vendor library — just `Wire`, so you can see exactly what goes on the bus.

```cpp
#include <Wire.h>
#define SCD41_ADDR 0x62

uint8_t crc8(const uint8_t *data, uint8_t len) {
  uint8_t crc = 0xFF;
  for (uint8_t i = 0; i < len; i++) {
    crc ^= data[i];
    for (uint8_t b = 0; b < 8; b++)
      crc = (crc & 0x80) ? (crc << 1) ^ 0x31 : (crc << 1);
  }
  return crc;
}

void sendCmd(uint16_t cmd) {
  Wire.beginTransmission(SCD41_ADDR);
  Wire.write(cmd >> 8);
  Wire.write(cmd & 0xFF);
  Wire.endTransmission();
}

bool dataReady() {
  sendCmd(0xE4B8);                 // get_data_ready_status
  delay(1);
  Wire.requestFrom(SCD41_ADDR, 3);
  uint8_t b[3];
  for (int i = 0; i < 3; i++) b[i] = Wire.read();
  if (crc8(b, 2) != b[2]) return false;
  return ((b[0] << 8 | b[1]) & 0x07FF) != 0;   // low 11 bits
}

void setup() {
  Serial.begin(115200);
  Wire.begin();                    // ESP32 default SDA=21, SCL=22
  sendCmd(0x21B1);                 // start_periodic_measurement
  delay(5000);                     // first sample after ~5 s
}

void loop() {
  if (dataReady()) {
    sendCmd(0xEC05);               // read_measurement
    delay(1);
    Wire.requestFrom(SCD41_ADDR, 9);
    uint8_t d[9];
    for (int i = 0; i < 9; i++) d[i] = Wire.read();
    // validate all three CRCs before trusting anything
    if (crc8(d,2)==d[2] && crc8(d+3,2)==d[5] && crc8(d+6,2)==d[8]) {
      uint16_t co2 = d[0] << 8 | d[1];
      float t  = -45.0f + 175.0f * (d[3] << 8 | d[4]) / 65535.0f;
      float rh = 100.0f * (d[6] << 8 | d[7]) / 65535.0f;
      Serial.printf("CO2 %u ppm  T %.1f C  RH %.0f %%\n", co2, t, rh);
    }
  }
  delay(5000);
}
```

## Pressure and altitude compensation

NDIR readings depend on gas density, so ambient pressure matters. Two ways to correct it:

- **`set_ambient_pressure` (0xE000)** takes pressure in **hPa** and can be sent **during** periodic measurement — ideal if you have a BMP280 nearby and want live correction.
- **`set_sensor_altitude` (0x2427)** takes meters above sea level but is **idle-mode only**; set it once at boot and let the sensor assume standard pressure for that altitude.

Skipping this at, say, 1500 m introduces a systematic error of several percent. Pick one method — do not apply both.

## The self-calibration trap

**Automatic Self-Calibration (ASC) is enabled by default**, and it will silently corrupt your data if you misuse it. ASC assumes that over a rolling window the sensor periodically sees fresh outdoor air at ~400 ppm, and it re-anchors its baseline to the minimum it observes. Its documented requirements: exposure to ~400 ppm fresh air at least weekly and a minimum of ~4 hours of continuous operation per week.

The failure modes are predictable once you know the assumption:

- A sensor sealed in a stuffy room that never sees 400 ppm will drag its baseline **too high**, so real readings drift low over weeks.
- Exposure to concentrations **below** 400 ppm (rare, but possible outdoors near vegetation) degrades accuracy with ASC on.

For a device that runs 24/7 in a normally ventilated home, leave ASC on. For a sensor in a grow tent, a sealed enclosure, or one powered on only occasionally, **disable it with `set_automatic_self_calibration_enabled` (0x2416)** in idle mode and perform a manual forced recalibration against a known reference instead.

## Takeaways

- The SCD41 measures true CO2 via photoacoustic NDIR; VOC-based eCO2 parts only estimate it and are fooled by solvents and breath alike.
- Address 0x62, `start_periodic_measurement` (0x21B1), poll `get_data_ready_status`, then `read_measurement` (0xEC05) on a 5 s cadence.
- Validate the per-word CRC-8 (poly 0x31, init 0xFF) or you will log phantom spikes.
- Apply pressure or altitude compensation, and understand ASC before you trust long-term numbers.

**Try next:** Log CO2 for one evening in an occupied room, then crack a window and watch the curve. If it falls from 1200+ ppm toward ~450 within minutes, your ventilation math checks out — and you have just proven your sensor tracks real CO2, not a VOC guess.
