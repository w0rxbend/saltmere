That purple breakout board floating around AliExpress for under two dollars — the one silkscreened `ENS160+AHT21` — is the cheapest way to put "air quality" numbers on a screen. It stacks two I2C parts: ScioSense's **ENS160**, a four-channel metal-oxide (MOX) gas sensor that outputs AQI, TVOC, and eCO2, and Aosong's **AHT21**, a temperature/humidity sensor. Before you trust the numbers, understand what one of them actually is.

## eCO2 is not CO2

The ENS160 has no way to count CO2 molecules. A real CO2 sensor (like an SCD41) is NDIR: it shines infrared through a chamber and measures how much the CO2 absorbs. The ENS160 instead heats a metal-oxide film and measures how its resistance changes as volatile organic compounds (VOCs) adsorb onto it. From that VOC signal it computes **eCO2** — "equivalent CO2" — using the empirical fact that in an occupied room, human-exhaled VOCs and human-exhaled CO2 rise together.

So eCO2 tracks *people and cooking and solvents*, not carbon dioxide. Open a bottle of hand sanitizer next to it and eCO2 spikes to 2000+ ppm with no change in real CO2. It's a useful "is this room stuffy?" proxy and a terrible ventilation-compliance instrument. Treat TVOC (ppb) as the honest primary reading and eCO2 as a derived convenience. If you need true CO2, buy an NDIR sensor.

## Addressing and modes

The two chips sit at different I2C addresses, so they share one bus cleanly:

- **AHT21** is fixed at `0x38`.
- **ENS160** is `0x52` when its ADDR pin is low, `0x53` when high. These combo boards tie it high, so scan for `0x53`.

The ENS160's `OPMODE` register (`0x10`) selects the state: `0x00` deep sleep, `0x01` idle, `0x02` **standard** (active gas sensing), `0xF0` reset. You want standard mode for continuous readings. Two timing facts from the datasheet matter: a **~3 minute warm-up** after power-on before readings settle, and up to **1 hour of initial conditioning** the very first time a fresh sensor runs. Discard early data — the validity flag in `DATA_STATUS` tells you when the sensor considers itself warmed up.

## Feeding compensation

MOX resistance drifts with temperature and humidity, so the ENS160 accepts external T/RH to compensate. That's the entire reason the AHT21 shares the board. You write:

- `TEMP_IN` (`0x13`): temperature in **Kelvin × 64**.
- `RH_IN` (`0x15`): relative humidity in **percent × 512**.

You don't need to pack those bytes by hand — the SparkFun library takes Celsius and percent directly and does the math. Push fresh values every read.

## Reading all three on an ESP32

Install two real libraries via the Arduino Library Manager: **SparkFun Indoor Air Quality Sensor - ENS160** (`SparkFun_ENS160`) and **Adafruit AHTX0** (which covers the AHT20/AHT21).

```cpp
#include <Wire.h>
#include <SparkFun_ENS160.h>   // "SparkFun Indoor Air Quality Sensor - ENS160"
#include <Adafruit_AHTX0.h>    // "Adafruit AHTX0"

SparkFun_ENS160 ens160;
Adafruit_AHTX0  aht;

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);          // ESP32 default SDA=21, SCL=22

  if (!aht.begin())            { Serial.println("AHT21 not found");  while (1); }
  if (!ens160.begin(0x53))     { Serial.println("ENS160 not found"); while (1); }

  ens160.setOperatingMode(SFE_ENS160_RESET);
  delay(100);
  ens160.setOperatingMode(SFE_ENS160_STANDARD);
}

void loop() {
  sensors_event_t humidity, temp;
  aht.getEvent(&humidity, &temp);

  // Push compensation BEFORE reading gas data
  ens160.setTempCompensationCelsius(temp.temperature);
  ens160.setRHCompensationFloat(humidity.relative_humidity);

  if (ens160.checkDataStatus()) {          // true once a new, valid sample is ready
    Serial.printf("T=%.1fC RH=%.1f%%  AQI=%d  TVOC=%dppb  eCO2=%dppm\n",
                  temp.temperature,
                  humidity.relative_humidity,
                  ens160.getAQI(),          // 1..5 (UBA scale)
                  ens160.getTVOC(),         // ppb
                  ens160.getECO2());        // ppm-equivalent, NOT real CO2
  }
  delay(1000);
}
```

`checkDataStatus()` gates on the sensor's own "new data valid" flag, so the first few minutes stay quiet until warm-up completes. AQI here is the 1–5 UBA index (1 = excellent, 5 = unhealthy), not the US EPA 0–500 AQI — another label that looks familiar and means something different.

Label your dashboard accordingly: TVOC in ppb, eCO2 as "eCO2 (VOC-derived)". Honest units are the whole game with cheap air-quality sensors.

**Try next:** Log TVOC and eCO2 to InfluxDB or MQTT for a day, then wave a marker pen or open a window near the sensor and watch eCO2 move — proof it's tracking VOCs, not carbon dioxide.
