# Saltmere

A personal daily learning journal, published automatically twice a day (09:00 & 21:00 Europe/Kyiv) by a scheduled Claude task.

Each run researches the web and a curated reading list, then writes 1–3 short, **implementable** articles across a rotating set of topic tracks:

- **Distributed Systems** — following *Distributed Systems* (4th ed.) by van Steen & Tanenbaum
- **Practical Linux Tools** — CLI tools and small systems experiments
- **Scala 3 & the JVM**
- **IoT & Embedded** — Arduino, ESP32, air-quality sensors, large IoT backends
- **Monitoring & Observability**
- **CAD & 3D Printing** — FreeCAD (parametric), KiCad, print pipeline

## How it's built

- Static site generated by **Jekyll** (GitHub Pages zero-build).
- Articles live in `_articles/<track>/` as Markdown with front matter (`title`, `date`, `track`, `summary`, `tags`, `sources`, `reading_time`).
- The home page (`index.md`) lists the latest articles and groups everything by track.
- Layouts in `_layouts/`, styles in `assets/style.css`.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

## Adding an article

Create `_articles/<track>/YYYY-MM-DD-slug.md`:

```yaml
---
title: Your title
date: 2026-07-24
track: linux-tools        # one of the track ids in _config.yml
summary: One-sentence hook.
reading_time: 4
tags: [example, cli]
sources:
  - title: Source name
    url: https://example.com
---

Article body in Markdown…
```
